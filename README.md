# 提瓦特地图工坊（Genshin-Style-Map-Creation）

原神风格的手绘地图**制作器**：用画笔涂出地形（海洋 / 草地 / 森林 / 山地 / 沙滩 / 道路），程序实时渲染成手绘质感地图——真实高度场驱动的等高线（疏密随坡度）、海拔分带设色、悬崖立面与投影、自动沙滩 / 浅滩 / 岸波；再摆放 20 种 2.5D 手绘风装饰物与地名标注，支持程序化世界生成、工程存档与 PNG 导出。

- 交接与架构文档：[HANDOFF.md](HANDOFF.md)
- 运行：`python tools/serve.py` → http://127.0.0.1:8932（或直接双击 `index.html`）
- 字体：仓库**不含**原神字体文件（版权原因）。将你持有的字体放置为
  `assets/fonts/genshin.ttf` 即可启用（或运行 `python tools/copy_font.py`）；
  缺失时自动回退系统字体，功能不受影响。

## 功能

- **地形笔刷**：六种地形拖拽涂画，海洋即橡皮擦；笔刷大小 `[` `]` 可调；道路宽度随噪声自然起伏。涂刷同时写入**真实高度场**（山地隆起、草林缓丘、沙滩压低，道路贴附地形不改动高度）。
- **真实等高线**：marching squares 从高度场提取等高线，坡陡线密、坡缓线疏，只绘于陆地；密度（层数）可在渲染面板调节。
- **海拔分带设色**：草地 / 森林颜色随海拔连续过渡（低地深绿 → 坡地中绿 → 平缓亮黄绿），再叠加水彩色块；悬崖立面与投影由高度梯度驱动——画一块高地，东南侧自动出现岩壁与投影。
- **程序化世界生成**：域扭曲分形噪声高度场 + 径向衰减生成群岛大陆，湿度噪声决定森林分布；海平面 / 森林密度 / 山地占比 / 地貌规模四个滑杆直接控制占比（分位数校准）。
- **材质与过渡**：地块之间按覆盖度做点彩融合过渡（不生硬）；全图叠加水彩颗粒与色相微抖；海岸自动生成沙滩层（湿润暗带）、浅滩层与三道起伏岸波；描边内侧一圈赛璐璐受光亮边。
- **渲染设置（渲染选项卡）**：自动沙滩层 / 浅滩层的开关与宽度、海岸描边强度、悬崖立体感、等高线纹理、色块纹理强度、手绘扭曲强度——分层参数完全交给用户控制。
- **地区风格**：蒙德 / 璃月 / 稻妻 / 层岩 四套色板一键切换。
- **装饰物（20 种）**：民居、大屋、教堂、哨塔、风车、码头、村落、城墙、桥梁、树木、松树、果树、岩石、草丛、碎石、遗迹、传送锚点、七天神像、营地、标记——俯视 2.5D 手绘风、统一左上光源与偏移投影；点击放置、拖拽移动、右键或删除模式移除、双击编辑。
- **散布植被笔刷**：按住拖拽，按大小 / 角度 / 种类随机撒下树丛草石，打破死板排列。
- **地名标注**：文字图层，双击可改字。
- **图层树**：装饰物按建筑 / 自然 / 地标 / 文字标注分组显隐，带实时计数（借鉴 Leaflet 图层控制）。
- **图层显示**：装饰物 / 地名标注图层可独立显隐（存入工程）。
- **视图**：滚轮缩放（0.5×~4×）、中键或按住空格拖拽平移、右上角放大 / 缩小 / 适应窗口。
- **历史记录**：`Ctrl+Z` 撤销 / `Ctrl+Y` 重做，各 30 步，覆盖地形与装饰。
- **工程存档**：`💾 存档` 下载 `.teyvat.json` 工程文件，`📂 读档` 导入；编辑内容自动保存到浏览器 localStorage，下次打开自动恢复。
- **导出**：当前地图连同装饰导出 1600×900 PNG。

## 渲染原理（简述）

工具以**高度场**为地基：涂鸦与程序化生成都写入一张 352×198 的高度网格，等高线（marching squares 提取）、海拔分带设色、悬崖立面与投影（高度梯度）、水深层次全部由它派生——这正是「元素贴附在地形上生长」的关键。类型涂鸦（草/林/山/沙/路）作为语义层与高度场并行：山笔刷写高高度，路笔刷只写类型不改高度。

渲染时先把每类地形模糊成"覆盖度场"，逐像素按 0.5 等值线分类得到亚像素级光滑边界（大片同质区走采样捷径）；森林边缘叠中频噪声成扇贝状；地块交界按次覆盖度做点彩融合；海岸按距离场生成沙滩层（湿润暗带）、浅滩层、三道岸波、白沫与深色描边；全图叠水彩颗粒；最后叠加矢量装饰物。工程文件（v2）同时保存类型网格与高度场，旧版 v1 工程读入时按类型合成高度。
